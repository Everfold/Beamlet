# 规范基础约定

## 规范性关键词

按 RFC 2119 区分强制等级：

- **必须（MUST）** / **不得（MUST NOT）**：硬性契约约束，违背即不合规。
- **应当（SHOULD）** / **不应当（SHOULD NOT）**：默认要求，仅在明确记录原因时允许偏离。
- **可以（MAY）**：允许的实现自由度。

## 跨模块通用规则

1. **核心原语与载荷不透明**：核心原语的身份与业务载荷对协调层完全不透明，不得解析业务内容，不得以内容相等替代身份相等。
2. **标识精确匹配**：凡字符串形式的原语身份、会话标识与能力标识，均须非空且按精确字面值匹配，不得修剪空白、折叠大小写或作隐式兼容。
3. **本地单调时钟**：凡超时、租约存活与排空期限判定，均基于观测方自身本地单调时钟计算，不依赖发送方时间戳或跨节点时钟同步。
4. **正数有限期限**：凡有限期限（如租约期限与等待超时）均必须为正数。
5. **逻辑 IDL 定位**：Protobuf Edition 2026（[messages.proto](proto/beamlet/v1/messages.proto)）仅定义跨角色逻辑消息结构，任意业务载荷以 `bytes` 表示，不规定线编码格式或具体传输中间件。
6. **术语书写准则**：正文使用中文，核心原语、生命周期状态与协议概念保留英文原词，词义以 [00-glossary.md](00-glossary.md) 为准。
