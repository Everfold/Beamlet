# Operation 外层记录

本层持有不可变请求及当前生命周期状态, 使用最小内核判断转换是否合法.

## 数据

Operation 包含唯一身份与请求内容, 创建后不通过本层接口修改. 身份类型与请求结构由调用者定义. 内容相同而身份不同的 Operation 是不同请求.

一个记录将一个 Operation 与它的当前生命周期状态绑定. 新记录从 Ready 开始, 后续转换继续使用同一记录. 本层不提供任意替换 Operation 或状态的接口.

## 转换

| 动作 | 记录的职责 | 调用者的职责 |
| --- | --- | --- |
| 创建 Attempt | 使用绑定的 Operation 身份调用内核, 保存成功返回的等待状态, 返回 Attempt | 提供未使用的 Attempt 身份, 保存返回的 Attempt |
| 接受 Report | 使用绑定的 Operation 身份校验报告关联, 保存成功返回的 Ready | 保证 Attempt 已结束, 保存完整 Report 与结果 |
| 结束 Operation | 保存成功返回的 Closed, 允许重复结束 | 决定何时结束 |

失败不改变当前状态. 生命周期转换不改变 Operation 的身份与原始请求.

报告是否满足请求由调用者判断. 接受报告后, 调用者可以创建新的 Attempt, 也可以结束 Operation.

## 保存与身份约束

记录在自身持有的数据中更新状态. 持久化与原语数据的保存由调用者负责.

调用者保证 Operation 身份唯一, 并为每次新 Attempt 提供未使用的身份. 同一 Operation 的转换通过对应记录进行, 本层不提供跨记录的身份去重与并发更新协调.

内核仍只读取输入并返回结果, 不保存或修改外层记录.
